# Spanish I Build Guide

Status: approved source-of-truth rules for future Spanish I curriculum work.

## Course Spine

- Homeschool Spanish Academy High School Level 1 is the spine for Spanish I.
- Supplemental materials follow the HSA sequence instead of forming a parallel course.
- Duolingo is supplemental practice only.
- The proficiency target is ACTFL Novice High, moving toward emerging Intermediate Low.
- Build and review one module at a time before moving on to the next module.

## Learners

- Materials are learner-focused first.
- Victor and Spencer receive the same academic level.
- Academic level is determined by ability, not age.
- Partner conversations are written for Victor and Spencer to practice together.
- Partner work should include role switching.
- Partner work should progress from modeled, to scaffolded, to unscripted.

## Spanish Usage

- Use idiomatic, broadly understood native Spanish.
- Label meaningful regional variation when it matters for learner understanding or real-world usage.
- Every Spanish example in learner-facing material includes an English translation.
- Store Spanish and English as separable content when possible so the website can later support an English on/off toggle.
- Projects may intentionally remove English when the task is designed as a transfer task and students should use prior lessons, dictionaries, or independent lookup.

## Printable Materials

- Printable packet pages are designed for US Letter.
- Printable materials should feel professional and appropriate for language learning.
- Use meaningful diagrams and graphics, not decoration.
- Minimize reliance on color so pages remain useful when printed in grayscale.
- Include exactly one Parent / Instructor / Facilitator reference page at the end of each module.
- Handouts should include intentional note-taking spaces near new words, pattern discovery, personal examples, and likely pronunciation reminders.
- Curriculum content should define note-taking opportunities; the website project decides exact visual placement and styling.
- Printable packets should be transformed into professional learner-facing workbook design, not rendered as curriculum outlines or planning lists.

## Website And Audio

- All audio lives on companion webpages, not in PDFs.
- Printable pages use Listen on Website markers where learners should use website audio.
- Longer readings receive Kindle Colorsoft-friendly versions.
- Curriculum drafts explicitly mark audio targets so implementation can create the matching audio asset and button.
- Website lessons should support embedded audio beside the exact word, sentence, or conversation being practiced.

## Reading And Assessment

- Supported readings may sit slightly above the students' current productive Spanish when context, audio, English support, and familiar subject matter make the input comprehensible.
- Comprehension questions can stretch recognition through multiple choice.
- Written-response questions should use answer structures students can reasonably retrieve from the passage.
- Personalized interactions should show correct Spanish, English translation when appropriate, and pre-produced audio for each selectable result.

## Flashcards

- Flashcards are a recurring layer for every unit, not an optional add-on.
- Flashcards should reinforce pronunciation, high-frequency words, patterns, and communication chunks rather than duplicating the full textbook vocabulary list.
- Use audio on flashcards whenever the card depends on pronunciation, listening, or conversational recall.
- Use images selectively when they add memory connection, humor, emotional engagement, or cultural connection.
- Avoid images for abstract sounds, grammar rules, and every single vocabulary item.
- Target roughly 60-70% clean audio/text cards and 30-40% illustrated cards.
- Flashcard style should be modern language learning with gentle illustration: professional, engaging, and not childish.
