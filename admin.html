Claire's class upload routine

  1. Rename files clearly, such as homework-01.pdf.
  2. Upload shared student files to materials/all-kids/curriculum-01/ or parent-only files to materials/parent/curriculum-01/.
  3. Open data/materials.json in GitHub and add the generated entry inside the materials list.
  4. Save the change. GitHub Pages will update the website shortly after.

Report card routine

  1. Replace the child's PDF at reports/spencer/current-report-card.pdf or reports/victor/current-report-card.pdf.
  2. Update the same child entry in data/report-cards.json.
  3. Keep the same report ID, such as spencer-current, so the report card section does not duplicate entries.
