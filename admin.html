Weekly Updates

Parent tools

Use the current-week setting to move the kids through the HSA sequence. Use the entry helper only when you add child-specific homework or extra practice.

Set the current week

  1. Open data/site-config.json.
  2. Change currentScheduleNumber to the curriculum number you want, from 1 to 30.
  3. Save the file and refresh the site.
{
  "programTitle": "Homeschool Spanish Academy High School Level 1",
  "currentScheduleNumber": 1,
  "currentLabel": "Current Week"
}

Claire's class upload routine

  1. Rename files clearly, such as homework-01.pdf.
  2. Upload child-specific files to materials/child-name/curriculum-01/ in the GitHub repository.
  3. Open data/materials.json in GitHub and add the generated entry inside the materials list.
  4. Save the change. GitHub Pages will update the website shortly after.

Report card routine

  1. Replace the child's PDF at reports/spencer/current-report-card.pdf or reports/victor/current-report-card.pdf.
  2. Update the same child entry in data/report-cards.json.
  3. Keep the same report ID, such as spencer-current, so the report card section does not duplicate entries.
