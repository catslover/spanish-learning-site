# U1.1 Pronunciation Workshop Flashcard Specification

Status: approved for website implementation.

## Purpose

The U1.1 flashcard deck reinforces pronunciation, listening, and early communication. It is not a duplicate of the HSA Lesson 1 vocabulary list.

## Deck Mix

- Sound recognition cards: 5 vowel cards.
- Tricky alphabet cards: 8-10 high-value cards.
- Pronunciation word cards: about 25-30 cards.
- Conversation chunk cards: 5-8 cards.
- Illustrated cards: about 30-40% of the deck.
- Clean audio/text cards: about 60-70% of the deck.

## Required Card Types

### Sound Recognition Cards

Cards:

- A
- E
- I
- O
- U

Audio:

- letter sound
- selected example words

Image: no image needed.

### Tricky Alphabet Cards

High-value letters:

- H / hache
- J / jota
- Ñ / eñe
- Q / cu
- R / erre
- V / uve
- Y / ye
- Z / zeta

Image guidance:

- Use an illustrated `Ñ / eñe` character.
- Consider a playful but not childish `J / jota` illustration.
- Do not illustrate every letter.

### Pronunciation Word Cards

Examples:

- `casa` / house
- `mesa` / table
- `vino` / wine
- `rojo` / red
- `luna` / moon
- `hola` / hello
- `hermano` / brother
- `José` / Joseph
- `jugar` / to play
- `niño` / boy / child
- `mañana` / tomorrow / morning
- `España` / Spain
- `queso` / cheese
- `quince` / fifteen
- `gato` / cat
- `gente` / people
- `pero` / but
- `perro` / dog

Every Spanish word card should have word audio.

### Minimal Pair Cards

Use these as a required U1.1 contrast:

- `pero`: but; single tap r; no image.
- `perro`: dog; rolled rr; image recommended.

### Conversation Chunk Cards

Include 5-8 chunks, such as:

- `Hola.` / Hello.
- `¿Cómo te llamas?` / What is your name?
- `Me llamo ___.` / My name is ___.
- `¿Cómo se escribe?` / How do you spell it?
- `¿Cómo se escribe tu nombre?` / How do you spell your name?

Every Spanish conversation chunk should include English translation and audio.

## Suggested Illustrated Cards

Use gentle, course-quality illustrations for selected cards:

- `niño`: child wearing hockey gear.
- `perro`: cute dog.
- `casa`: small colorful Spanish-style house.
- `Ñ / eñe`: memorable letter character.
- `¿Cómo se escribe?`: pencil or speech bubble.

## Implementation Requirements

- Flashcards support front and back content.
- Front side includes Spanish and audio.
- Back side includes English, notes, and example sentence when useful.
- Spanish examples always include English translation.
- Audio is stored as a file path, not only generated by browser speech.
- Images are optional per card.

## Initial Website Deck

The first implementation can begin with a smaller curated U1.1 deck and grow toward the full inventory. It should include:

- all five vowel sound cards
- `ñ`, `h`, `j`, `qu`, `r/rr`
- `niño`, `hola`, `José`, `que`, `pero`, `perro`
- at least two conversation chunks
